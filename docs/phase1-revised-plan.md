# 第一階段修訂計畫

研究截止：2026-10-13。此文件規劃採用確認後的工作，本次沒有開始平台開發。唯一首選是方案B；版本與授權見[調查](github-research-report.md)、[架構](recommended-architecture.md)與[法律門檻](license-review.md)。

## 階段目標與科學承諾

第一階段提供**已知或已校正參數的 RP 梯度模擬與比較**。輸入可以含SMILES作化合物識別，但不宣称SMILES自动產生可靠logKw/S。無足夠參數時顯示「尚無可用模型／需要校正」，不能填上看似精確的Rt。HILIC、NP、IEX、SEC可進入資料契約與研究清單，各模式只啟用通過獨立驗證的模型。

## 採用前門檻

1. 使用者確認方案B與copyleft部署策略；核對PyLSS AGPL、CADET-Core LICENSE／標頭衝突、CADET-Process GPL與相容版本。保存notice與相應原始碼提供策略。
2. 在獨立環境建立CADET-Core／Process最小三成分案例，測solver退出、峰、單位、質量平衡、網格收斂。尚未實測的CADET不能直接替代已測的RP路径。
3. 對PyLSS建立必要科學驗證：解析极限、單位、dwell、零／負梯度、未洗脫；核對峰寬与Rs的定義。NLSS匯入與參數索引先修正及驗證，未修前停用。
4. 建立已知實驗RP基準與保留外部測試集，核對適用範圍，才能對外宣稱準確度。合成profile僅證明運算接線。

## 明確不必重新開發的功能

|工作|重用對象|保留條件／剩餘工作|
|---|---|---|
|RP LSS解析Rt、logKw/S擬合|PyLSS ssengine|封裝現有函式；單位與邊界修正、外部驗證|
|初步RP梯度搜尋|PyLSS optseparation、gradientutils|重用搜尋／評估核心；確認Rs公式及約束、未洗脫、成本函數|
|理想Gaussian色譜圖數值|PyLSS plotengine|可重用公式／數值；交互圖形、混合峰与顯示層需新做|
|通用柱傳輸／binding求解|CADET-Core|完成本機與授權門檻後重用；不另寫整套GRM求解器|
|unit operation、事件／方法、solver adapter、最佳化框架|CADET-Process|借用或整合其科學架構；不是整站fork；用固定相／物種參數|
|LKM／GRM對照案例|STLC|研究／回歸對照，不需要同時維護兩套正式主求解器|
|肽類Rt預測與校正|DeepLC選配|日後獨立模型服務與資料條件驗證；不納入RP零參數核心|
|target anchor Rt映射|2-step選配|確認權重授權及特徵／domain後重用，不把它當梯度求解器|

這些可免去成熟數值模組的從零實作，但不能免除產品資料模型、校正、驗證、依賴管理與授權工作。尚無工時基線，不提供節省百分比或精確週數。

## 仍須自行開發

- 化學實體輸入／正規化、名稱解析的選配來源、SMILES／序列／混合物與批次schema；結構繪製與手機操作。
- method／column／mode／parameter的單位及版本契約；標記來源是實測、擬合、預訓練或假設。
- API與任務執行、快取、可重現run manifest、錯誤處理及React結果介面。
- 模型適用域、校正／驗證拆分、誤差與不確定性：資料不足不能顯示數值可信度；參數擾動的敏感度不等於統計prediction interval。
- 公平的模式／柱／梯度比較、約束與成本函數：只比較已具參數且各自驗證的候選，不為缺失模式虛構排名。
- NP與HILIC競爭吸附／水層與pH機制、SEC尺寸／孔徑排阻、IEX蛋白／鹽／電荷與交換參數；各模式單獨研發／校準。
- 溫度、pH、管柱轉移、峰寬／非對稱／過載的實驗驗證；聚合物分布與蛋白的結構／尺寸／電荷不能當作普通小分子LSS。

## 執行順序與驗收

|順序|可審查結果|驗收條件|
|---|---|---|
|0 採用決策|版本／授權／資產清單|阻擋項解決，使用者確認後才開發|
|1 科學基線|現有RP adapter與已知參數案例|Rt/峰寬單位一致；無效方法／未洗脫明確回報；基準可重現|
|2 校正與验证|少量梯度Rt擬合、留出資料報告|fit與test分開，domain有依據；無資料則不宣稱精度|
|3 圖形與API|三成分／方法修改／色譜對照|能修改%B、時間、柱並追溯輸入及模型；手機／桌面可操作|
|4 梯度比較|約束內候選與可解釋排名|Rs定義一致、未洗脫處理一致；不只最大化理想峰距|
|5 第二模式研究|CADET IEX或SEC最小案例|選一個有參數／驗證資料的模式；不以RP模型直接複製|
|6 選配結構模型|MIT QSRR／TIMPANI／2-step／DeepLC之一|合法權重與資料、固定method domain、外部validation；非第一階段前置條件|

## 備選方案切換

若copyleft公開來源／部署策略不接受，或CADET版本與license衝突無法解決，切換唯一備選方案C：獨立設計並驗證必要的RP／SEC方程式實作，以NumPy／SciPy／RDKit等適當授權基礎套件支援；可日後採MIT OpenIEX，但先處理平衡參數與solver狀態問題。不得以換語言、微服務或僅改API假設可以規避上游授權。

本次研究已可縮小開發範圍；上述實作與科學修正全部留待採用確認。
