# EluSim_V1 使用者測試回報

回報日期：2026-10-13。公開網站：[EluSim](https://elusim-v1.onrender.com)。

使用者已分別使用手機及電腦開啟 EluSim_V1 公開網頁，表示兩個版本均可正常開啟與基本操作，暫時沒有發現明顯的介面問題。

使用者目前沒有準備 LC 測試化合物與實驗數據，因此**尚未手動驗證 Run Simulation、梯度調整後的模擬結果、Optimize Gradient 的計算功能**。此回報只確認網站開啟及基本操作，不能記為 LC 科學計算、梯度最佳化或實驗準確度驗證通過。
